# NI Dev Conf 2026

Proofs of concept (POCs) and general resources for my NI Dev Conf 2026 talk.

## POCs

- [MeshCore demo](demo-poc/) — connect to a radio, send a message, and read incoming messages.
- [OpenTUI demo](demo-tui-poc/) — a terminal UI with an interactive counter.
- [Ink demo](demo-tui-poc-ink/) — a React-based terminal UI.

These are experiments built for the talk and may need local setup or hardware to run.

## Talk resources

This repository also serves as a home for general resources, notes, and links supporting the talk. More will be added as the talk takes shape.
